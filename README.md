Пять задач варианта: класс-счётчик; класс для файлов; банковский счёт; мини-ORM; сериализация объекта в JSON.

У счётчика рядом с `up` / `down` есть «перегрузка оператора +»: складываются значения, а не сами объекты.

## Запуск

```bash
python main.py
python -m pytest
```

Демонстрация печатает сумму счётчиков, круг записи и чтения временного файла, баланс, строку из sqlite и профиль после JSON. Временный каталог делает `tempfile`, в дерево работы он не сохраняется.

## Модули

`Counter` (`counter.py`) держит целое поле `value`. `up` прибавляет шаг, `down` вычитает. Выражение `Counter + Counter` создаёт новый счётчик с суммой, исходные значения остаются прежними.

`TextFile` (`files.py`) пишет строку на диск в UTF-8 и читает её обратно.

`BankAccount` (`bank.py`) не принимает отрицательный старт. `deposit` увеличивает баланс и возвращает его. `withdraw` уменьшает баланс. Если сумма больше остатка или не положительна, метод бросает `ValueError` и баланс не трогает.

`MiniTable` (`orm.py`) заводит таблицу `id INTEGER PRIMARY KEY, title TEXT, qty INTEGER`. `insert` отдаёт сохранённую строку вместе с `id`. `select_all` возвращает все строки, в них видны те же `title` и `qty`.

`Profile` (`json_codec.py`) переводит имя и город в JSON-строку и собирает объект обратно. После круга поля совпадают.
